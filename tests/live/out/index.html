Live-pilot probe bundle

This page only hosts probe.js: the platform's own discovery and extraction modules (text, adapters, field rules, normalisation, robots.txt reader) bundled for a browser. It lets a reviewer run the same code the crawler runs on the exact document an official website serves, and compare the output with the official notice by eye.

  • Reads only public GET URLs on the page's own origin. No logins, forms, captchas or access-control workarounds.
  • Sees served HTML only; JavaScript-rendered content is invisible to it, exactly as it is to the crawler.
  • PDF text uses pdf.js 6.1.200, the version bundled in the server's PDF reader.
// on an official site's page, in the browser console
await new Promise(r => { const s = document.createElement("script"); s.src = "<this artifact>/probe.js"; s.onload = r; document.head.append(s); });
